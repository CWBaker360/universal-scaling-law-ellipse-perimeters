# Main Result

Let \(P_N\) be the equal-parameter polygonal perimeter of the ellipse and let
\(P\) be its exact perimeter. Then

\[
P_N
=
P\,\operatorname{sinc}\!\left(\frac{\pi}{N}\right)
+
O(e^{-\rho N})
\]

for every \(0<\rho<\operatorname{artanh}(b/a)\). Hence

\[
\frac{P-P_N}{P}
=
\frac{\pi^2}{6N^2}
-
\frac{\pi^4}{120N^4}
+
O(N^{-6})
+
O(e^{-\rho N}).
\]

The tripling correction

\[
\widehat P_N=\frac{9P_{3N}-P_N}{8}
\]

satisfies

\[
\frac{P-\widehat P_N}{P}
=
\frac{\pi^4}{1080N^4}
+
O(N^{-6})
+
O(e^{-\rho N}).
\]
